# 🚀 My God-Tier Termux Setup

This repository contains my personal dotfiles for a high-end, neon-themed Termux environment.

## ✨ Features
- **Shell:** Zsh with Oh My Zsh & Powerlevel10k theme.
- **Plugins:** Syntax highlighting, Autosuggestions, Zoxide, FZF.
- **Visuals:** Custom Fastfetch config, Tokyo Night (Neon) colors.
- **Tools:** LSD (icons), Bat (syntax cat), Tmux (dashboard), CMatrix.

## 🛠️ Installation
Run the `install.sh` script to set up everything automatically.
